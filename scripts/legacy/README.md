# Legacy Scripts

Pasta para scripts retirados do fluxo ativo do repositorio.

Regra:

- mover para ca quando o script nao participa do pipeline oficial, do site, dos jobs diarios ou dos testes relevantes;
- manter por pouco tempo, so enquanto houver duvida se ainda vale algo;
- excluir de vez depois que a utilidade remanescente for zero.

Subpastas atuais:

- `engine/`: entrypoints legados de experimentacao.
- `sim/`: simulacoes ou sinteticos sem uso atual no fluxo.
- `bench_portfolio/`: benchmark isolado sem referencias ativas.
- `research/`: sobras de pesquisa avulsa antigas.
